# ClothSwap

ClothSwap is a clothing exchange marketplace where users can list clothes, browse available items, save items to a wishlist, and send swap requests to other users.

## Features

- User registration and login
- JWT-based authentication
- Add clothing listings
- Browse and search clothing items
- Filter items by category and size
- View item details
- Edit and delete your own listings
- Save items to a wishlist
- Send swap requests
- Accept or reject swap requests
- MongoDB database storage

## Technologies Used

### Frontend
- React
- Vite
- React Router

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt
